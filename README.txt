======================================================================
  COJADS ⇔ ELAN 変換ツール（COJADS2ELAN）  Version 1.0
======================================================================

日本語諸方言コーパス（COJADS）の談話データ（音声 wav ＋ 文字化・注釈の
csv / Excel）を、音声注釈ソフト ELAN の注釈ファイル（.eaf）に変換します。
また、ELAN で編集した eaf を、COJADS 形式の csv / Excel に戻すこともできます。

  日本語諸方言コーパス（COJADS）: https://www2.ninjal.ac.jp/cojads/index.html

  ELAN: https://archive.mpi.nl/tla/elan

----------------------------------------------------------------------
1. 対象データ
----------------------------------------------------------------------

  ・csv / Excel → ELAN の変換には wav ファイルが必要です。COJADS の音声（wav）ファイルは、有償版でのみ入手できます。

  ・本ソフトウェアの動作確認は、COJADS_Ver.2026.03_Paid（有償版）の
    配布データを用いて行いました。


----------------------------------------------------------------------
2. 動作環境
----------------------------------------------------------------------

  Windows 10 / 11（64 ビット）。インストールは不要です。
  COJADS2ELAN.exe を任意のフォルダに置いて使います。

  ※ 初めて実行すると、Windows の SmartScreen やウイルス対策ソフトが
    警告を出すことがあります（開発者の署名がない exe のため）。
    SmartScreen の場合は「詳細情報」→「実行」で起動できます。

  ※ 起動時に内部のファイルを展開するため、起動に数秒かかります。


----------------------------------------------------------------------
3. 使い方
----------------------------------------------------------------------

COJADS2ELAN.exe をダブルクリックすると画面が開きます。
画面上部の 2 つのタブで、変換の向きを選びます。

■ csv / Excel → ELAN（青のタブ）

  1. 「wav ファイル」の［参照…］で音声ファイルを選ぶ
  2. 「注釈ファイル」の［参照…］で csv または Excel ファイルを選ぶ
     （同じフォルダに同じ名前のファイルがあれば、自動で入ります）
  3. 必要なら「出力 eaf ファイル」を指定する
     （空欄なら、注釈ファイルと同じ場所に「同じ名前.eaf」で作成）
  4. 「注1〜注3 の層」の作り方を選ぶ（後述）
  5. ［変換実行］を押す

  例: 13_a_099_demo.wav ＋ 13_a_099_demo.csv → 13_a_099_demo.eaf

■ ELAN → csv / Excel（緑のタブ）

  1. 「eaf ファイル」の［参照…］で ELAN のファイルを選ぶ
  2. 「ひな形」に、もとの csv / Excel を指定する
     （同じフォルダに同じ名前のファイルがあれば、自動で入ります）
  3. 出力形式（csv / Excel）を選ぶ
  4. 必要なら「出力ファイル」を指定する
     （空欄なら、eaf と同じ場所に「名前_fromELAN.csv / .xlsx」で作成）
  5. ［変換実行］を押す

  画面下部に、処理の経過や警告が表示されます。

  画面右上の［このソフトについて］で、利用条件・連絡先と、
  同梱ソフトウェアのライセンス全文を表示できます。


----------------------------------------------------------------------
4. 入力ファイルの形式（csv / Excel → ELAN）
----------------------------------------------------------------------

■ 文字コード・形式
  csv   … UTF-8（BOM 付き・なし）または Shift_JIS。自動で判別します。
  Excel … .xlsx / .xlsm の先頭シート。1 行目を見出しとして読みます。
          古い形式の .xls には対応していません（.xlsx で保存し直してください）。

■ 使用する列
  xmin            … 発話の開始時間（秒）
  xmax            … 発話の終了時間（秒）
  話者            … 話者ごとに注釈層（ティア）を作ります
  ID              … 発話の ID
  方言テキスト
  標準語テキスト
  注1番号・注1語形・注1注釈・注2… ・注3注釈（ない場合もあります）

  県・地点・収録年月日などのその他の列は、eaf には取り込みません
  （ELAN → csv / Excel の変換で、ひな形から引き継ぎます）。


----------------------------------------------------------------------
5. 作成される eaf の構成（csv / Excel → ELAN）
----------------------------------------------------------------------

話者ごとに、次の順で注釈層（ティア）を作ります（例: 話者 C）。

  C                … ID（xmin〜xmax の時間を持つ親ティア）
  C_方言テキスト   … 親ティアに 1 対 1 で従属
  C_標準語テキスト … 同上
  C_注1番号 など   … 同上（注1〜注3 の番号・語形・注釈）

■ 注1〜注3 の層の作り方
  列自体がない場合 … 層は作りません
  列がある場合     … 画面で次のどちらかを選びます
    ・値を持つ話者にのみ作る（初期設定）
    ・値がなくても全話者に作る

■ 表示順の設定ファイル（.pfsx）
  ELAN は eaf と同じ名前の .pfsx ファイルに、ティアの表示順などを保存します。
  本ツールは eaf と同時に、.pfsx にも上記のティア順を書き込みます。
  既存の .pfsx がある場合は、ティア順だけを書き換えます（色などの設定は残します）。

■ 時間の精度
  ELAN の時間はミリ秒単位のため、xmin・xmax はミリ秒に丸められます。

■ 警告
  同じ話者の発話の時間が重なっている場合などは、画面下部に警告を表示します。


----------------------------------------------------------------------
6. COJADS 形式に戻す際の規則（ELAN → csv / Excel）
----------------------------------------------------------------------

  ・ひな形と話者・ID が一致する発話
      … ひな形の行をもとに、時間と注釈の列を eaf の値で更新します。
        時間を ELAN で動かしていない発話は、もとの値（0.6169375 など）を
        そのまま残します。
  ・ELAN で追加した発話
      … 新しい行として出力します。ID は空になります。
        県・話者生年など、その話者で値が一定の列はひな形から補います。
  ・ELAN で削除した発話
      … 出力しません。
  ・ELAN で追加した注釈層（ティア）
      … 新しい列として末尾に加えます（例: 「C_メモ」→ 列「メモ」）。
        従属しない独立のティアは、時間の重なる発話の行に値を入れます。

  ひな形を指定しない場合は、xmin・xmax・ID・話者と注釈の列だけを出力します。

  出力する csv は BOM 付き UTF-8 です（Excel でそのまま開けます）。
  Excel で出力する場合、もとのファイルの書式（列幅・色など）は引き継ぎません。


----------------------------------------------------------------------
7. 既存ファイルの扱い
----------------------------------------------------------------------

出力先に同じ名前のファイルがある場合は、上書きせず、同じ場所の
「old」フォルダに「ファイル名_yyyymmdd」（同じ日に複数回なら _2, _3 …）
として退避してから、新しいファイルを作成します。
.pfsx は old にコピーを残したうえで、ティア順だけを書き換えます。
